Dropping the no-cycles rule

A tree is a connected graph with no cycles. Remove that restriction and you have a graph — the most general structure in the course, and the one that models roads, networks, dependencies and social ties. Everything in the last three chapters is about traversing it.

Definition — graph

A graph \(G = (V, E)\) is a set of vertices \(V\) and a set of edges \(E\), where each edge joins two vertices. In an undirected graph an edge has no direction; in a directed graph (a digraph) each edge is an ordered pair \((u, v)\), drawn as an arrow.

Worked example — a tree as a graph

The non-recursive definition says: a graph is a tree if it is connected and acyclic. Equivalently, it is connected and has exactly \(n - 1\) edges.

Check on the tree from chapter 3: 7 vertices, 6 edges, connected, no cycle. Any connected graph with 7 vertices and 7 edges must contain a cycle — that is the pigeonhole argument behind the equivalence.

The two representations

Adjacency matrixAdjacency list
Space\(O(V^2)\)\(O(V + E)\)
Edge lookup (u,v)\(O(1)\)\(O(\deg(u))\)
Enumerate neighbours of u\(O(V)\)\(O(\deg(u))\)
Good forDense graphs; constant-time edge testsSparse graphs; every traversal

A simple undirected graph on \(V\) vertices has at most \(V(V-1)/2\) edges. If \(E\) is close to that, the graph is dense and the matrix is reasonable. If \(E\) is close to \(V\), it is sparse and the matrix wastes almost all its space.

Why this matters for the next three chapters

BFS and DFS both enumerate the neighbours of every vertex exactly once. With an adjacency list that costs \(O(V + E)\) in total. With a matrix it costs \(O(V^2)\), because you scan an entire row to find a handful of neighbours. Using the wrong representation silently turns a linear traversal into a quadratic one.

Worked example — the same graph, both ways

Graph with vertices 1..4 and edges (1,2), (1,3), (2,4).

Adjacency matrix (4×4, symmetric for undirected):

Matrix16 cells, 6 non-zero
      1 2 3 4
  1 [ 0 1 1 0 ]
  2 [ 1 0 0 1 ]
  3 [ 1 0 0 0 ]
  4 [ 0 1 0 0 ]

Adjacency list (4 lists, 6 entries total):

ListsV + 2E entries for undirected
1 -> [2, 3]
2 -> [1, 4]
3 -> [1]
4 -> [2]

For an undirected graph each edge appears twice in the list, so the total is \(V + 2E\).

C implementation

Cgraph.c
#include <stdio.h>
#include <stdlib.h>

/* ---- adjacency list ---- */
typedef struct Adj {
    int v;
    struct Adj *next;
} Adj;

typedef struct {
    int n;
    Adj **head;
} Graph;

Graph *graph_new(int n) {
    Graph *g = malloc(sizeof *g);
    g->n = n;
    g->head = calloc(n, sizeof(Adj *));   /* zeroed: no edges yet */
    return g;
}

void add_edge(Graph *g, int u, int v) {
    Adj *a = malloc(sizeof *a);
    a->v = v; a->next = g->head[u]; g->head[u] = a;   /* push at head, O(1) */
    Adj *b = malloc(sizeof *b);
    b->v = u; b->next = g->head[v]; g->head[v] = b;   /* omit for a digraph */
}

void graph_free(Graph *g) {
    for (int i = 0; i < g->n; i++) {
        Adj *a = g->head[i];
        while (a) { Adj *nx = a->next; free(a); a = nx; }
    }
    free(g->head);
    free(g);
}

void print_graph(const Graph *g) {
    for (int i = 0; i < g->n; i++) {
        printf("%d ->", i);
        for (Adj *a = g->head[i]; a; a = a->next) printf(" %d", a->v);
        printf("\n");
    }
}

int main(void) {
    Graph *g = graph_new(5);
    add_edge(g, 0, 1); add_edge(g, 0, 2);
    add_edge(g, 1, 3); add_edge(g, 2, 4);
    print_graph(g);
    graph_free(g);
    return 0;
}
Pythongraph.py
from collections import defaultdict


def build_adjacency_list(edges, directed=False):
    """O(V + E) space."""
    g = defaultdict(list)
    for u, v in edges:
        g[u].append(v)
        if not directed:
            g[v].append(u)
    return g


def build_adjacency_matrix(n, edges):
    """O(V^2) space - only for dense graphs."""
    m = [[0] * n for _ in range(n)]
    for u, v in edges:
        m[u][v] = 1
        m[v][u] = 1
    return m


if __name__ == "__main__":
    edges = [(0, 1), (0, 2), (1, 3), (2, 4)]
    adj = build_adjacency_list(edges)
    for v in sorted(adj):
        print(v, "->", adj[v])
    # 0 -> [1, 2]
    # 1 -> [0, 3]
    # 2 -> [0, 4]
    # 3 -> [1]
    # 4 -> [2]

Check your understanding

A connected undirected graph has 12 vertices. What is the maximum number of edges it can have without being a multigraph?
A simple undirected graph on n vertices has at most n(n−1)/2 edges — every pair connected once. Here 12·11/2 = 66. Eleven edges would be the minimum, forming a tree.
Which representation should you use for a social network with 1,000,000 users where each has about 200 friends?
10^6 × 10^6 = 10^12 matrix cells — about a terabyte at one byte each, for a graph with only about 10^8 edges. The adjacency list stores V + 2E ≈ 2×10^8 entries, three orders of magnitude smaller.

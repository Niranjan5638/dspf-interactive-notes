Going as deep as possible

DFS follows one path until it dead-ends, then backtracks. It uses a stack — explicitly, or implicitly through recursion — and it produces far more structural information than BFS because it records when each vertex is entered and left.

PseudocodeDFS with timestamps
time = 0

DFS-VISIT(G, u):
    time = time + 1;  disc[u] = time;  colour[u] = GREY
    for each neighbour v of u:
        if colour[v] == WHITE:
            parent[v] = u
            DFS-VISIT(G, v)
    colour[u] = BLACK
    time = time + 1;  fin[u] = time

DFS(G):
    for each vertex u: colour[u] = WHITE; parent[u] = nil
    for each vertex u:
        if colour[u] == WHITE: DFS-VISIT(G, u)

Each vertex is entered once and each edge examined once, so the cost is \(O(V + E)\). The recursion stack uses \(O(V)\) space in the worst case — a path graph.

What DFS is used for

Cycle detection

Undirected: a back edge to a non-parent ancestor means a cycle. Directed: a back edge to a grey vertex means a cycle. BFS cannot do this cheaply because it does not track the recursion path.

Topological sort

A topological order of a DAG lists every vertex before all of its successors. Two methods: run DFS and output vertices in decreasing order of finish time, or repeatedly remove a vertex of in-degree zero (Kahn's algorithm). A topological order exists if and only if the graph is acyclic.

Worked example — topological sort

Edges 1→2, 1→3, 2→4, 3→4. In-degrees: 1:0, 2:1, 3:1, 4:2.

Kahn: remove 1 (only in-degree 0), then 2 and 3 become available. Removing them in either order gives 1, 2, 3, 4 or 1, 3, 2, 4. Both valid — the order is not unique.

DFS method: finishing times give 4 last, then 2, 3, 1. Reversing gives 1, 3, 2, 4.

Strongly connected components

A digraph is strongly connected if there is a path both ways between every pair. Kosaraju's algorithm does two DFS passes — one on the graph, one on the reversed graph in decreasing finish-time order. Tarjan's does it in one pass with low-link values. Both are \(O(V + E)\).

2-edge-connected components

An edge is a bridge if removing it disconnects the graph. A graph is 2-edge-connected when it has no bridges. DFS detects them with low-link values: an edge (u, v) is a bridge when low[v] > disc[u].

BFS or DFS?

If you need the shortest number of edges, or the vertices near the source, use BFS. If you need structure — cycles, bridges, topological order, strong connectivity — use DFS. Both are \(O(V+E)\); the difference is what they remember.

C and Python

Cdfs.c
#include <stdio.h>

#define MAXV 100
int adj[MAXV][MAXV], deg[MAXV], n;
int colour[MAXV];        /* 0 = white, 1 = grey, 2 = black */
int disc[MAXV], fin[MAXV], timer = 0;
int has_cycle = 0;

void dfs_visit(int u, int parent) {
    colour[u] = 1;                       /* grey: on the stack */
    disc[u] = ++timer;
    for (int k = 0; k < deg[u]; k++) {
        int v = adj[u][k];
        if (colour[v] == 0) {
            dfs_visit(v, u);
        } else if (v != parent && colour[v] == 1) {
            has_cycle = 1;               /* back edge to a grey vertex */
        }
    }
    colour[u] = 2;                       /* black: finished */
    fin[u] = ++timer;
}

void dfs(int s) {
    for (int i = 0; i < n; i++) { colour[i] = 0; disc[i] = fin[i] = 0; }
    timer = 0; has_cycle = 0;
    dfs_visit(s, -1);
}

int main(void) {
    n = 5;
    int edges[][2] = {{0,1},{0,2},{1,3},{1,4}};
    for (int i = 0; i < 4; i++) {
        int u = edges[i][0], v = edges[i][1];
        adj[u][deg[u]++] = v;
        adj[v][deg[v]++] = u;
    }
    dfs(0);
    for (int i = 0; i < n; i++) printf("%d: disc %d fin %d\n", i, disc[i], fin[i]);
    printf("cycle: %s\n", has_cycle ? "yes" : "no");
    return 0;
}
Pythondfs.py
def dfs(adj, source):
    """Iterative DFS with discovery and finish times. O(V + E)."""
    disc, fin, parent = {}, {}, {}
    timer = 0
    stack = [(source, iter(adj.get(source, ())))]
    disc[source] = timer = timer + 1
    parent[source] = None

    while stack:
        u, it = stack[-1]
        advanced = False
        for v in it:
            if v not in disc:
                disc[v] = timer = timer + 1
                parent[v] = u
                stack.append((v, iter(adj.get(v, ()))))
                advanced = True
                break
        if not advanced:
            stack.pop()
            fin[u] = timer = timer + 1
    return disc, fin


def topological_sort(adj, vertices):
    """Kahn's algorithm. Returns None if the graph has a cycle."""
    indeg = {v: 0 for v in vertices}
    for u in vertices:
        for v in adj.get(u, ()):
            indeg[v] += 1
    ready = [v for v in vertices if indeg[v] == 0]
    order = []
    while ready:
        u = ready.pop()
        order.append(u)
        for v in adj.get(u, ()):
            indeg[v] -= 1
            if indeg[v] == 0:
                ready.append(v)
    return order if len(order) == len(vertices) else None


def has_cycle_directed(adj, vertices):
    """White/grey/black colouring. Grey neighbour = back edge = cycle."""
    WHITE, GREY, BLACK = 0, 1, 2
    colour = {v: WHITE for v in vertices}

    def visit(u):
        colour[u] = GREY
        for v in adj.get(u, ()):
            if colour[v] == GREY:
                return True
            if colour[v] == WHITE and visit(v):
                return True
        colour[u] = BLACK
        return False

    return any(colour[v] == WHITE and visit(v) for v in vertices)

Check your understanding

In an undirected graph, DFS encounters an edge to a vertex that is already visited and is not the parent. What does this prove?
In an undirected graph, non-tree edges are always back edges to an ancestor. An ancestor is reachable from the current vertex, and the current vertex is reachable from the ancestor, so together they form a cycle.
A directed graph has a topological order. What must be true of it?
A topological order exists if and only if the graph is acyclic — that is the definition of a DAG. A cycle would require some vertex to come before itself. It must have a source (in-degree 0) and a sink (out-degree 0), but those are consequences, not the definition.

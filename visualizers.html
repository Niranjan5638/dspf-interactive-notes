Interactive Visualizers

Drive the algorithms yourself: stack, queue, BST, heap, BFS/DFS and growth rates.

Every visualizer below is live. Use the controls to step forward and back, or press play and change the speed. Each one logs what is happening in the panel underneath, so you can read the algorithm's reasoning as it runs rather than just watching shapes move.

Growth rates

Drag the slider to change \(n\) and watch how the operation counts separate. The bars are drawn on a logarithmic scale so that all seven remain visible — which is itself the point: on a linear scale, \(2^n\) would flatten everything else to nothing.

Growth-rate explorer

Stack and queue

Push and pop to see LIFO; enqueue and dequeue to see FIFO. The log names which element moves and why.

Stack and queue

Binary search tree

Insert keys and watch the shape form. The log shows the inorder traversal, which is always sorted — the property that makes a BST an ordered map. Insert 10, 20, 30, 40, 50 in that order and watch it degenerate into a chain.

Build a BST

Heap

Insert values and watch them sift up; extract the maximum and watch the last leaf move to the root and sift down. The index labels under each cell are the array positions — parent of i is floor((i-1)/2).

Max-heap

BFS and DFS

The same graph, both traversals. Green vertices are finished, red is the vertex being processed, and blue is the current frontier. Switch between BFS and DFS and watch the frontier change from a queue to a stack — and the visit order change with it.

Graph traversal

A note on dependencies

The visualizers are plain JavaScript with no library — they run offline once the page is cached. The only external dependencies on this site are Google Fonts (typography), MathJax (equations) and Prism (syntax highlighting). If any of them fails to load, the page still works: text falls back to system fonts, equations degrade to readable notation, and code appears unstyled but correctly.

Chapter 08

Breadth-First Search

Ring-by-ring exploration with a queue, shortest unweighted paths, components and bipartiteness.

Exploring in rings

BFS visits every vertex at distance 1, then every vertex at distance 2, and so on. It uses a queue — which is the payoff for chapter 2, and the reason level-order tree traversal in chapter 3 is the same algorithm in disguise.

Definition — BFS

Starting from a source \(s\), mark \(s\) discovered and enqueue it. While the queue is non-empty, dequeue a vertex \(u\), and for each unvisited neighbour \(v\), mark it discovered, record \(\text{dist}[v] = \text{dist}[u]+1\) and \(\text{parent}[v] = u\), and enqueue it.

PseudocodeBFS
BFS(G, s):
    for each vertex v:
        dist[v] = infinity; parent[v] = nil; visited[v] = false
    dist[s] = 0; visited[s] = true
    Q = empty queue; enqueue(Q, s)

    while Q is not empty:
        u = dequeue(Q)
        for each neighbour v of u:
            if not visited[v]:
                visited[v] = true
                dist[v] = dist[u] + 1
                parent[v] = u
                enqueue(Q, v)

Each vertex is enqueued at most once and each edge is examined at most twice (once from each endpoint, in an undirected graph), so the cost is \(O(V + E)\) with an adjacency list.

Why BFS finds shortest paths

Vertices are dequeued in non-decreasing order of distance. When a vertex \(v\) is first reached from \(u\), \(u\) is the closest undiscovered-from vertex, so the path through \(u\) is as short as any. This is the invariant that makes BFS correct for unweighted shortest paths.

Exam trap

BFS minimises the number of edges, not the total weight. On a weighted graph it is wrong. Counterexample: vertices A, B, C with A–B costing 10, A–C costing 1 and C–B costing 1. BFS from A reaches B in one edge and reports distance 1, but the cheapest path is A→C→B at cost 2 against the direct 10. Dijkstra's algorithm, which uses a priority queue instead of a queue, is the correct tool.

What BFS is used for

Connected components

Run BFS from an unvisited vertex, marking everything reached; increment a counter and repeat from the next unvisited vertex. The number of restarts is the number of components, and the total cost is still \(O(V + E)\).

Bipartiteness

Two-colour the graph by the parity of the BFS distance. If any edge ever joins two vertices of the same colour, the graph contains an odd cycle and is not bipartite. The test is exact, not heuristic, and it is a single BFS.

Worked example — testing bipartiteness

Triangle 1–2–3–1. BFS from 1: dist[1]=0 (colour A), dist[2]=1 (colour B), dist[3]=1 (colour B). Edge 2–3 joins two B vertices of the same colour, so the graph is not bipartite — correctly, because a triangle is an odd cycle.

Square 1–2–3–4–1. BFS from 1: colours A, B, A, B. Every edge joins different colours, so it is bipartite.

Diameter

The longest shortest-path in the graph. Running BFS from every vertex and taking the maximum distance is exact, at \(O(V(V+E))\). From a single source you get that vertex's eccentricity, not the diameter — a distinction exam questions like to test.

C and Python

Cbfs.c
#include <stdio.h>
#include <stdlib.h>

#define MAXV 100
int adj[MAXV][MAXV], deg[MAXV], n;   /* adjacency matrix, small graphs */

/* returns the number of vertices reached */
int bfs(int s, int dist[], int parent[]) {
    int visited[MAXV] = {0};
    int queue[MAXV], front = 0, rear = 0, reached = 0;

    for (int i = 0; i < n; i++) { dist[i] = -1; parent[i] = -1; }

    visited[s] = 1; dist[s] = 0;
    queue[rear++] = s;

    while (front < rear) {
        int u = queue[front++];
        reached++;
        for (int k = 0; k < deg[u]; k++) {
            int v = adj[u][k];
            if (!visited[v]) {
                visited[v] = 1;
                dist[v] = dist[u] + 1;
                parent[v] = u;
                queue[rear++] = v;
            }
        }
    }
    return reached;
}

int main(void) {
    n = 5;
    int edges[][2] = {{0,1},{0,2},{1,3},{1,4}};
    for (int i = 0; i < 4; i++) {
        int u = edges[i][0], v = edges[i][1];
        adj[u][deg[u]++] = v;
        adj[v][deg[v]++] = u;
    }
    int dist[MAXV], parent[MAXV];
    printf("reached %d\n", bfs(0, dist, parent));
    for (int i = 0; i < n; i++) printf("dist[%d] = %d\n", i, dist[i]);
    return 0;
}
/* output:

Pythonbfs.py
from collections import deque


def bfs(adj, source):
    """Returns (order, dist, parent). O(V + E)."""
    dist = {source: 0}
    parent = {source: None}
    order = []
    q = deque([source])

    while q:
        u = q.popleft()
        order.append(u)
        for v in adj.get(u, ()):
            if v not in dist:
                dist[v] = dist[u] + 1
                parent[v] = u
                q.append(v)
    return order, dist, parent


def components(adj, vertices):
    """Count connected components by repeated BFS."""
    seen, count = set(), 0
    for s in vertices:
        if s in seen:
            continue
        count += 1
        order, dist, _ = bfs(adj, s)
        seen.update(order)
    return count


def is_bipartite(adj, vertices):
    """Two-colour by BFS distance parity. O(V + E)."""
    colour = {}
    for s in vertices:
        if s in colour:
            continue
        colour[s] = 0
        q = deque([s])
        while q:
            u = q.popleft()
            for v in adj.get(u, ()):
                if v not in colour:
                    colour[v] = 1 - colour[u]
                    q.append(v)
                elif colour[v] == colour[u]:
                    return False          # odd cycle
    return True


if __name__ == "__main__":
    adj = {1: [2, 3], 2: [1, 4, 5], 3: [1, 6, 7], 4: [2],
           5: [2, 8], 6: [3], 7: [3], 8: [5]}
    order, dist, parent = bfs(adj, 1)
    print("order:", order)
    print("dist :", dict(sorted(dist.items())))
    print("bipartite:", is_bipartite(adj, adj.keys()))

Check your understanding

Which data structure does BFS require, and why?
FIFO ordering is what makes BFS explore in rings: everything discovered at distance d is processed before anything at distance d+1. A stack would give DFS; a priority queue gives Dijkstra.
A graph has 8 vertices and 7 edges and is connected. What does BFS from vertex 1 produce?
A connected graph with V−1 edges is a tree, so BFS reaches every vertex and its parent edges form a spanning tree — here the graph itself. In general the BFS tree is a spanning tree of the source's component.
